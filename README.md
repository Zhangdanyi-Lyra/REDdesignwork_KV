# 城市纯玩 · 附近，另有玩法

基于 HTML、Canvas、CSS 和原生 JavaScript 的交互海报。图片、字体和交互均在浏览器本地运行，无需后端、数据库或模型 API。

## 本地运行

在仓库目录执行：

```sh
python3 -m http.server 8080
```

浏览器打开 http://localhost:8080 。本地 HTTP 服务仅用于静态文件预览，不是作品运行所需的后端。

## 交互

- 点击 GO 后开始落词，左右拖动括号或使用方向键接词。
- 生成最多 10 个图案，每次至少包含一个人物。
- 人物保持彩色；物体和地点初始为灰色，碰到人物后变彩色 3 秒，再次碰撞刷新计时。
- 图案持续移动、旋转和碰撞；支持实时调整大小及动效参数。
- 标题先显示“城市纯玩”，迸发结束后切换为“附近，另有玩法”。
- 支持展开内容长图、两段文案打字机效果和保存画面。

## 文件

- `index.html`、`app.js`：可直接部署的静态入口。
- `assets/`：人物、物体、地点、Figma 视觉素材和字体。
- `src/engine.js`：词库、运动与碰撞。
- `src/render.js`：画布绘制。
- `src/ui.js`：按钮、输入和状态控制。
- `src/index.template.html`：页面样式与结构。
- `asset-manifest.json`、`scene-catalog.json`：本地素材映射。

修改 `src/` 后执行 `python3 build.py` 重新生成入口。构建仅使用 Python 标准库；访客使用页面不需要 Python。

## 部署

将仓库根目录作为静态站点根目录，无需安装依赖或构建。也可运行 `python3 build.py` 后部署。此仓库只保存前端作品，不自动开启公开访问。
